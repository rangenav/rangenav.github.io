# RangeNav

Project website for **RangeNav: Task-Aligned LiDAR Range-Image Pretraining for Robot Navigation**, Robotic Systems Lab, ETH Zurich.

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Edit `index.html` for content and `static/css/rangenav.css` for styling. No build step is required.
